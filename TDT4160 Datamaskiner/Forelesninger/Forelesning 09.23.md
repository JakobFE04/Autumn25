# Flyttall & flersykelprosessor

## Flyttall
Læringsutbytte T3.3

Vi lar komma flytte på seg, derfor flyttall.

Basert på vitenskapelig notasjon
- 1123 = 1,123 x 10³ 
- 0,001123 = 1,123 x 10⁻³
- ->Gjennom å endre på eksponenten kan vi representere både veldig store og veldig små tall.
![[Pasted image 20250923102248.png]]
- Flere «fraction» bit øker presisjon → Vi kan representere tall mer nøyaktig 
- Flere «exponent» bit øker «range» → Vi kan representere større og mindre tall

Med flyttall kan vi få under og overflyt når tallet er for lite eller for stort til å kunne representeres med "exponent".

For eksempel med tall-linje:
Maks $\pm$ 28672 og min $\pm$ 0.125 til 0.
Ender opp over maks for vi overflyt, ender vi opp i mellom min og 0 får vi underflyt.
