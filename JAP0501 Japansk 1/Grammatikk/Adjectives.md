# Present tense P.132

|                | Affermative | Negative   |
| -------------- | ----------- | ---------- |
| い              | さむいです。      | さむくないです。   |
| な              | げんきです。      | げんきじゃないです。 |
| いい (irregular) | いいです。       | よくないです。    |
# Past tense

|                | Affermative | Negative     |
| -------------- | ----------- | ------------ |
| い              | さむかったです。    | さむくなかったです。   |
| な              | げんきでした。     | げんきじゃなかったです。 |
| いい (irregular) | よかったです。     | よくなかったです。    |
