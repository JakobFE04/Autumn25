# あります　VS　います
P107: 
あります - Non living things
います    - Living things
Begge trenger fulle setninger, mens ting som がくせいです kan kortes ned.


# Utalelse:
Istedet for å utale setninger som ノ, utal heller som へ.
Tonen går opp tidlig også ned.
