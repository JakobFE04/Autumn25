# い & な-adjectives
P. 133
Present tense

|               | Affirmative<br> | Negative      |
| ------------- | --------------- | ------------- |
| い-Adjective:  | かわいいです。         | かわいくないです。     |
|               | いいです。           | よくないです。       |
|               | わるいでうす。         | わるくないです。      |
| な-Adjectives: | ひまですか。          | いいえ、ひまじゃないです。 |

|               | Affirmative<br> | Negative     |
