# Verb P.86
1. Short & long form
	- Dictionary form = short form affirmative
	- Long form ending = "ます"
2. Tense: Present & past only (NB! no future tense)
3. Three kinds of verbs:

## Ru-verb

| Short form (る) | Long form (ます) | Long form negative (ません) | Short form negative (ない) |
| -------------- | -------------- | ------------------------ | ------------------------ |
| おきる            | おきます           | おきません                    | おきない                     |

## U-verb

| Short form (う) | Long form (ます) | Long form negative (ません) | Short form negative () |
| -------------- | -------------- | ------------------------ | ---------------------- |
| いく             | いきます           | いきません                    |                        |


## Irregular verb
U-verb som slutter med R

| Short form (う) | Long form (ます) | Long form negative (ません) | Short form negative () |
| -------------- | -------------- | ------------------------ | ---------------------- |
| かえる            | かえります          | かえりません                   |                        |
| くる             | きます            | きません                     |                        |
|                |                |                          |                        |

Noun + する/します -> Verb

べんきょう＋する/します - studere
りょうり＋する/します - lage mat
しつもん＋する/します - spørre spørsmål
